# Maja & Jakub – svatební web

Static site (plain HTML/CSS/JS, no build step).

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Where to change things

| What | Where |
| --- | --- |
| Wedding date (countdown), Google Form link | `js/config.js` |
| Homepage texts, program, venue + map | `index.html` |
| Story (newspaper), gallery, colours, practical info | `pribeh.html` |
| Colours | CSS variables at the top of `css/style.css` |
| Map location | `index.html` → the `<iframe>` `q=` parameter and the "Navigovat" link |
| Photos | replace files in `img/foto/` (keep names, or update the `src`) |
| Invite in the envelope | replace `img/pozvanka.svg` with a photo/scan of the real invite (portrait, ~5:7) and update the `src` in `index.html` |

All current images are dummies generated by `python3 tools/generate_art.py`.

## Quiz facts

Facts for the wedding quiz are wrapped in `<span data-quiz="N">` in `pribeh.html`.
Guests don't see them; open `pribeh.html?kviz` to highlight and number them.
